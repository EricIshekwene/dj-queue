Decisions before the build

Everything the spec leaves open, on one page. Already decided in the spec (not asked again)
  1. Native Mac app, always running (background engine + menu bar)
  2. Manual posting first; Postiz later as an adapter
  3. Long-form is tracked only, uploaded by you in YouTube Studio
  4. Score 0–100, set only by you; no AI
  5. Launch sort worst → best, switchable; only unplanned items move
  6. 1 post a day, same video everywhere, staggered times
  7. No automatic spacing; overlap avoidance optional and off
  8. Weekly approval; runway always visible; low-runway alerts
  9. Editor: aspect, fixed crop, trim, text versions with timing, cover, captions
  10. Preview equals export; source files never touched
  11. Loudness −14 LUFS / −1 dBTP
  12. Too big → auto-compress; too long → trim for that platform
  13. Copyright: show loudly, no auto-retry, manual re-upload allowed
  14. Failed posts re-queue the next day after the fix
  15. Old TikTok library later
  16. Disk fine for now
  17. Doctor screen + CLI + Claude skill
